# Plan de curso — Fundamentos de Java para principiantes

## Secuencia de lecciones

### Lección 1: ¿Qué es programar y qué es Java?

- **Duración:** 6:09 min
- **Descripción:** Introducción a las instrucciones ordenadas, a Java y a la ejecución del primer programa en el navegador.
- **Video:** [Ver la lección 1](https://youtu.be/jMYmaWVjO6c).
- **Práctica en línea:** [Abrir el editor con el ejercicio de Hola mundo](PENDIENTE_URL_EDITOR_PRECARGADO_1).
- **Código:** [Archivo inicial](starter-files/lesson-01/Main.java) · [Ejemplo completo](completed-examples/lesson-01/Main.java).
- **Al finalizar:** el estudiante ejecuta un programa y cambia el mensaje que aparece en la consola.

### Lección 2: Variables y tipos de datos

- **Duración:** 6:21 min
- **Descripción:** Uso de variables `int` y `String` para guardar, mostrar y actualizar datos.
- **Video:** [Ver la lección 2](https://youtu.be/7BURV7fqZRk).
- **Práctica en línea:** [Abrir el editor con el ejercicio de nombre y edad](PENDIENTE_URL_EDITOR_PRECARGADO_2).
- **Código:** [Archivo inicial](starter-files/lesson-02/Main.java) · [Ejemplo completo](completed-examples/lesson-02/Main.java).
- **Al finalizar:** el estudiante crea variables y muestra un mensaje con sus valores.

### Lección 5: Bucles `for` y `while`

- **Duración:** 5 a 7 minutos previstos; registrar la duración real después de grabar.
- **Descripción:** Repite instrucciones con un contador, una condición y una salida; muestra los números del 1 al 5 de dos maneras.
- **Video:** pendiente de publicación como video no listado en YouTube.
- **Práctica en línea:** pendiente de crear el enlace directo al editor con el ejercicio precargado.
- **Código:** [Archivo inicial](starter-files/lesson-05/Main.java) · [Solución con `for`](completed-examples/lesson-05/Main.java) · [Solución con `while`](completed-examples/lesson-05/WhileExample.java).
- **Guion:** [Lección 5](scripts/lesson-05.md).
- **Al finalizar:** el estudiante crea un bucle con contador y reconoce cómo evitar que se repita indefinidamente.

### Lección 6: Métodos y entrada/salida

- **Duración:** 5 a 7 minutos previstos; registrar la duración real después de grabar.
- **Descripción:** Define un método con parámetro, lee un nombre con `Scanner` y muestra un saludo.
- **Video:** pendiente de publicación como video no listado en YouTube.
- **Práctica en línea:** pendiente de crear el enlace directo al editor con el ejercicio precargado.
- **Código:** [Archivo inicial](starter-files/lesson-06/Main.java) · [Ejemplo completo](completed-examples/lesson-06/Main.java).
- **Guion:** [Lección 6](scripts/lesson-06.md).
- **Al finalizar:** el estudiante llama a un método reutilizable con un dato recibido desde la consola.
