# Lección 3 — Operadores y expresiones

Duración objetivo: 5 a 7 minutos; usar la duración real en el plan final.

**Diapositiva 6 — Operadores.** «En el video anterior guardamos datos en variables. Ahora podemos hacer operaciones con ellos. Los símbolos `+`, `-`, `*` y `/` permiten sumar, restar, multiplicar y dividir. En Java escribimos el asterisco para multiplicar y la barra para dividir. También podemos comparar dos valores: `==` pregunta si son iguales. No confundas `==`, que compara, con `=`, que asigna un valor. Imagina un juego en el que tienes ocho puntos y ganas un bono de dos. ¿Cuántos puntos tendrías?».

**Diapositiva 7 — Expresiones.** «Una expresión combina valores y operadores y produce un resultado. La pantalla muestra `8 + 2 × 3`. Antes de revelar el resultado, calcula mentalmente: primero multiplicamos 2 por 3 y luego sumamos 8. El resultado es 14. Algunas expresiones producen números; otras comparan valores y producen `true` o `false`. Vamos a comprobarlo con Java».

**Pasar al editor después de la diapositiva 7.** Abrir o escribir `completed-examples/lesson-03/Main.java`. «Tenemos `puntos = 8` y `bono = 2`. Al mostrar `puntos + bono` usamos paréntesis para que Java sume antes de unir el resultado al mensaje. Predice la salida y ejecutemos: aparecen 10 puntos. Después evaluamos `8 + 2 * 3`, que da 14. Por último, `puntos == 10` es falso porque puntos vale 8; pero `puntos + bono == 10` es verdadero. Observa la diferencia entre obtener un número y obtener una respuesta verdadera o falsa».

**Práctica.** «Pausa el video, abre el ejercicio inicial y completa las tres operaciones. Cambia `puntos` a 10. ¿Qué comparaciones cambian? Ejecuta para verificarlo».

**Cierre.** «Usamos operadores para calcular y comparar, y vimos que una expresión produce un resultado. En la siguiente lección emplearemos una comparación para que nuestro programa tome una decisión».
